# MP0712 (Molecular Partners, MOLN) - Pricing Report

MP0712 is a DLL3-targeted Pb-212 Radio-DARPin. The active Phase 1/2a
study uses an imaging/dosimetry step followed by up to four therapeutic
Pb-212 doses. The model uses approved radioligand/radiopharmaceutical
prices as public proxies, with LUTATHERA selected as the primary proxy
because it is also a fixed four-dose radiopharmaceutical regimen.
